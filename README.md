# TC

A lightweight 3D game development platform.

## About

TC is an independent game development project
focused on building a lightweight, modular and
extensible 3D game engine.

## Goals

- Lightweight 3D rendering
- Low-poly game development
- Physics and collision systems
- 3D model and texture importing
- Integrated scene editor
- Cross-project asset management

## Technology

- C++
- OpenGL
- GLFW
- GLM
- CMake
